# 納税予測の入力保持・財務指標の表示調整

## 変更

- 納税予測で、月変更・会計データ再取得による手入力の上書きを修正。利益、資本金、仮受・仮払消費税ごとに自動反映と手入力を区別する。
- 旧保存データ、手入力の0・空欄・赤字を保持し、会計実績の再反映を明示操作にする。読込失敗中の編集と初期値保存を防ぐ。
- 顧問先・年度ごとにフォーム状態を分離し、金額単位・右揃え・税目表の横スクロールを調整する。
- 財務指標の長い名称と説明アイコンの縮みを調整する。メーターの数値をSVG直下へ置き、針の根元との重なりを解消する。

Webのみの変更。API、DBスキーマ、税率、税額計算、財務指標の判定ロジックは変更しない。保存JSONへの任意の `prefill` 情報追加は既存の汎用保存APIで扱う。DB migrationは不要。

## 検証

- 入力反映の回帰テスト9件、既存の財務指標判定テスト28件成功。
- 対象コードのESLint、Web全体のTypeScript検査・本番用ビルド成功。
- ローカル実アプリと検証用APIによる16項目のブラウザー確認成功。
- メーターの補正後は1720・1024・390px幅、スコア0・50・100、印刷用CSSで重なりがないことを確認。根元と数値領域の間隔は約9〜10px。

既存の自動保存には600msの待機がある。保存完了後の切替・再読込を確認した。保存前の離脱対策、保存失敗後の再試行改善、スマートフォン向け共通ヘッダーの調整は含めない。
