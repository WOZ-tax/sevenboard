# ストラック図・返済余力 (2026-09-18)

## 追加した画面

- `/strac`。既存のデザインを使い、変動損益の次にメニューを追加。
- ユーザー提供の `strac-chart.html` を参考に、実際のMF損益と借入返済予定表に接続。売上→変動費・限界利益→固定費・営業利益を分解。小さな帯の金額は図の下に配置する。
- 営業外損益・特別損益・税金を経て当期純利益に至る数値を併記。
- 限界利益率、営業利益の損益分岐点、経営安全率、固定人件費の労働分配率と、データに基づく説明。
- 増収・利益率改善・固定費削減のシナリオ、返済と目標資金を満たす必要売上高。
- `/help/strac`、印刷/PDF、表示単位の切替。

## 計算の境界

図は期首から選択月末までの累計。未来月は直近の経過月末までに制限し、デモではデータ基準日も上限にする。月途中から始まる変則期間は自動年換算しない。

返済余力は、基準月翌月から12か月の計画。実績を月数で割って12倍する。特別損益は繰り返さず、営業外損益は年換算。税金は正の税引前利益×想定税率 (初期30%) の簡易モデル。減価償却等を加え、運転資金増加・設備投資・その他調整を反映し、同じ12か月の予定元金返済を差し引く。利息を二重控除しない。

初期の資金調整は0円。前提を人が確認するまで「余力あり」と確定した表示にしない。資料更新・区分変更後は確認を無効化する。季節性、未計上費用、税務調整・均等割・納付時期、将来の利息変化、増収に伴う追加運転資金を別途確認する。返済余力は預金残高ではない。

予定表は全件取得し、完済までの元金・残高・日付・連番を確認。基準日の帳簿借入残高と照合。未登録・取得失敗・不整合は返済額未確認とし、0円扱いしない。手入力の年間元金総額は明示する。P/Lと費用内訳の不一致や保存前提の取得失敗も試算を保留する。

## 保存・権限

既存の認証済み `year-end-state/feature` APIを利用。`strac.assumptions.v1` は会社・会計年度・基準月別。明示的な保存で共有し、閲覧権限では保存不可。画面は会社と基準月で再マウントして入力を分離。

科目区分は既存の `variable-cost.custom-classification` を共有し、会社内全期間に反映。API・DB変更は不要。

## 検証

- 純粋計算テスト：12件。期跨ぎ、月途中・未来月、損益照合、分類変更、特別損益除外、年換算、赤字・不正値、目標売上の逆算、未登録・不完全予定表、帳簿突合。
- Next.js production build (型チェックを含む)。
- 隔離済みのデモ会社に通常ログイン。保存・再読込・基準月別分離・復元と、PDF・画面幅を検証。
- 外部への書込を遮断したAPI fixtureで、未登録・不完全予定表、取得失敗、P/L不一致、赤字、区分変更時の再確認、閲覧権限を検証。
- 検証記録・画面キャプチャはワークスペースの `output/sevenboard-strac/`。認証情報は収録しない。
