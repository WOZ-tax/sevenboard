## 主な指摘と修正

| 領域 | 修正後の動作 |
| --- | --- |
| 認可 | 担当者は担当会社のみ操作。停止スタッフ・停止事務所、旧割当情報、他事務所スタッフの指定も検証。 |
| CSRF | Cookie優先の認証とBearerヘッダーだけによるCSRF免除の不一致を解消。免除パスは完全一致。 |
| MF同期 | 単月推移の欠損を累計PLで埋めない。BSは実際のレポート月へ保存。初期取込も共通同期処理とMFの会計期間を使用。再同期は実際のMF取込・kintone読込を行う。 |
| 共通保存 | Content-Typeの重複によるJSON解析失敗を修正。値のない保存要求はAPIで400。復元完了前や会社・期変更時の誤保存を防止。 |
| 空応答 | 正常な200空本文・204はnullとして処理。壊れた非空JSONやHTTPエラーは失敗のまま扱う。 |
| 予算・予実 | 選択年度と実際の期首を使用。最新のセル入力と承認状態をDB保存。確定中の変更はAPIも拒否。部門予算への実績重複結合を修正し、対象月・単月/累計を反映。 |
| 仕訳明細 | 現行MFと旧形式の日付・科目・税込金額・摘要を表示。0円を保持。 |
| 借入 | MF残高と同日時点の返済予定を照合し、日付を明示。 |
| 決算予測 | 通期着地を前期通期と比較。資金繰りは最終実績の翌月から12か月。 |
| 納税予測 | 税引前利益を取得。手入力の0・赤字を保存。明示的な再反映で自動値に戻せる。防衛特別法人税は2026年4月1日以後開始年度から判定。 |
| 役員報酬 | 欠損保存項目によるNaNを防止。手入力を保持。選択月までの報酬・償却額を年換算し、資本金も実績から取得。 |
| 融資指標 | BSの0円の見出し行ではなく合計残高を使用。返済目安のネットCFの符号と年換算を修正。 |
| 月次レビュー | 棚卸資産の課税購入を対象外として誤検知する上流エンジンを修正。仕訳自体は変更していない。 |
| その他 | 不正なイベント種別の例外防止、業種情報の共有保存、デモの連携表示、未提供設定の準備中表示。 |

## デモの整合性

**青空ライフ用品卸株式会社（デモ）**、12月決算、資本金1,000万円、従業員8人。
2023～2025年の3期と2026年1～8月を収録。2022年は繰越・増加率検算用。同じ架空仕訳からPL・BS・推移表を生成し、全仕訳の貸借・56か月のBS・月次PL合計を検証。

## 依存・残る制約

- 本番依存のnpm監査: critical 0 / high 0 / moderate 4 / low 0（修正前33件、critical 1/high 16）。Next 16.3.5、SheetJS公式0.20.3等へ更新。
- 残る4件はNestのSSEフィールド注入と依存伝播。本APIに`@Sse`経路はない。Nestメジャー移行は別途。開発依存を含む監査は23件（high 10/moderate 10/low 3）で、全依存の無欠陥を意味しない。
- デモ実績は2026-08-31固定、保存は利用者全員に共有。自動リセットはない。初期作成スクリプトは重複作成を拒否し、リセットに使えない。
- マスタ編集・個別通知設定等には既存の未提供機能が残る。BS整理コメント等の次期実装表示も完成扱いにしていない。
- レビュー連携は前期仕訳を渡しておらず、その比較は未実施と表示される。前期実績の欠落ではない。
- サンプルの月次法人税等は税引前利益×30%の研修用仮定。税率別年税額予測とは別計算。AI文章・税予測は担当者が確認する補助情報。
- 役員報酬シミュレーターの個人住民税は既存の簡易式（所得税と同じ課税所得を基礎にする）であり、住民税固有の控除・非課税限度等の完全計算ではない。所得0の課税、法人赤字の切捨ては今回修正した。
