# オンボーディング用ヘルプ・担当者の一括操作

## 利用者向け

- `/help`：ログイン不要で共有できる14本のガイド。検索、カテゴリ、画像拡大、研修用チェック、印刷・PDF保存に対応。
- `/help/quickstart`：15分の操作順。財務諸表、月次レビュー、財務指標、ロカベン、源泉集計、決算検討を案内。
- 掲載画像は隔離されたデモ会社「青空ライフ用品卸株式会社（デモ）」で撮影。実績は2026-08-31まで。初期パスワード・実在会社の情報は含めない。
- アプリの「使い方・ヘルプ」、デモ帯の「デモの使い方」から開ける。
- オーナー：顧問先一覧 → 事務所スタッフ管理 → スタッフを一括登録。名前・メールアドレスの2列を貼り付け、確認して登録。
- オーナー：管理ポータル → 担当者を一括割当。複数社・複数スタッフを選び、会社ごとの追加件数を確認して実行。

## 一括管理の仕様

- 現在の事務所の有効なオーナーだけが操作可能。デモ利用者・デモ事務所への操作は拒否。
- スタッフは1回100名まで。Excel等の2列貼り付け、引用符付きCSV、任意の見出し行に対応。不正な列は黙って切り捨てない。
- 新規アカウントには個別の初期パスワードを発行。DBにはbcryptで保存。レスポンスはno-store、画面内だけに保持し、共有クエリキャッシュやブラウザ保存領域には保存しない。
- 初期パスワードCSVは新規ユーザーだけを含む。数式として解釈される値をエスケープ。自動メール送信は行わない。
- 既存ユーザーの名前・パスワード・登録済みのロールは変更しない。重複はスキップ。停止・解除・招待中、顧問先ユーザー、デモユーザーは一括処理で再有効化しない。
- 担当割当は1回100社・50名まで。全会社・全スタッフが同じ事務所に属することを確認してから追加。既存の割当・ロールは保持。閲覧者を新たに割り当てる場合はviewerロールを使用。
- 書き込みはSerializableトランザクション。処理時に権限と対象を再確認する。競合時は自動で再作成せず確認のやり直しを案内。
- 明示的な会社担当を持つオーナーでも、所属一覧にtenantRoleを保持するよう修正。
- DBスキーマ変更なし。
